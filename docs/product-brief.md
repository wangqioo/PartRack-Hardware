# 产品简述

PartRack 是面向创客、电子工作室、小型研发团队的桌面级智能物料架硬件系统。

核心价值链：

```text
扫码入库 -> NFC 碰一下 -> 找料点灯 -> BOM 拣料 -> 库存台账
```

一句话定义：

```text
手机里的货架和墙上的货架一起亮灯。
```

## 整体架构

```text
手机 APP  <--- BLE/NFC --->  批次单元 x N
  |                         - nRF52832 + NT3H2111 + 锂电
  |                         - 25 x WS2812B 底盘灯条
  |                         - 25 个纯结构磁吸料盒
  v
云端台账  <--- BLE ------->  共享取料坞 v1.5
                            - 光电计数
                            - 称重校准
```

本仓库负责右侧硬件域：批次单元、共享取料坞、BLE 协议、固件和硬件设计。左侧 Android APP 由 `Yrd980/LCSC_android_erp` 仓库维护。

## 设计原则

- 料盒是哑件：零电子、零接触点。
- 硬件是绑定关系的单一事实源：槽位、料号、数量存于 MCU flash。
- 自动计数能力收敛到共享取料坞，避免逐盒加传感器破坏成本和功耗模型。

## 主控选型策略

首版打样使用 nRF52832，优先保证固件开发余量和调试效率。nRF52811 保留为量产降成本备选，等固件尺寸、RAM 峰值、功耗和 OTA 方案实测后再评估切换。nRF52840 只作为开发验证板或高配实验平台，不作为当前底盘量产主控。

## 本仓库 v1 功能

- 智能底盘硬件与固件四态机。
- BLE 协议 v0.1。
- 绑定表读写、点灯控制、从硬件恢复所需 READ_ALL。
- NFC NDEF 路由载荷。
- OTA DFU。
